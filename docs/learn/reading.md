# Reading a workbook

xlspy has three read modes. Pick the lightest one that does the job.

| Mode | Builds | Styles | Use it for |
| :--- | :--- | :--- | :--- |
| `ExcelReader(path).get_rows()` | rows of values, streamed | no | ETL, DataFrames, bulk extraction |
| `load_workbook(path, read_only=True)` | openpyxl-style read-only sheets | no | coordinates, `iter_rows()`, `ReadOnlyCell` |
| `load_workbook(path)` | the full editable model | yes, lazily | random access, formatting, edits, save |

All three work for XLSX, XLSM and XLSB.

## Stream values with ExcelReader

<!-- runnable -->
```python
from xlspy import ExcelReader, Formula, XlsxWriter

with XlsxWriter("sales.xlsx") as workbook:
    workbook.add_sheet("Sales")
    workbook.write_sheet(
        [
            ["Product", "Units", "Revenue"],
            ["Coffee", 120, (12500, "0")],
            ["Tea", 90, (8400, "0")],
        ]
    )
    workbook.add_sheet("Notes")
    workbook.write_sheet([["Generated by xlspy"]])

with ExcelReader("sales.xlsx") as reader:
    print(reader.get_sheet_names())

    for row in reader.get_rows("Sales"):
        print(row)

    all_rows = reader.read_all("Sales", data_only=False)
    print(all_rows)
```

`get_rows()` streams values and does not retain previous rows. `read_all()`
collects them in memory.

## Values or formulas

`data_only=True` is the default: you get the stored value, including a formula's
cached result. Pass `data_only=False` to get formula text:

```python
with XlsxWriter("formulas.xlsx") as workbook:
    workbook.add_sheet("Data")
    workbook.write_sheet([["A", "B"], [2, 3], [None, Formula("A2+B2", value=5)]])

with ExcelReader("formulas.xlsx") as reader:
    print(reader.read_all("Data", data_only=True))   # [['A', 'B'], [2, 3], [None, 5]]
    print(reader.read_all("Data", data_only=False))  # [['A', 'B'], [2, 3], [None, '=A2+B2']]
```

## Load an editable model

```python
from xlspy import load_workbook

workbook = load_workbook("sales.xlsx")
sheet = workbook["Sales"]
print(sheet["A1"].value)
sheet["B2"] = 130
workbook.save("sales-updated.xlsx")
workbook.close()
```

`load_workbook()` returns formula text by default, like openpyxl. Styles are
resolved lazily: a workbook whose styles you never inspect loads almost as fast
as an unstyled one.

## Read-only mode

```python
workbook = load_workbook("large.xlsb", read_only=True)
for row in workbook["Sales"].iter_rows(min_row=1, max_row=5, values_only=True):
    print(row)
workbook.close()
```

Read-only sheets use worksheet coordinates, fill missing rows with empty rows and
cannot be edited or saved.

!!! tip "Which one is fastest?"
    `ExcelReader` is the fastest for values because it does not create a `Cell`
    per value. Use `load_workbook()` only when you need coordinates, styles or
    edits. See [Performance](../performance.md).
